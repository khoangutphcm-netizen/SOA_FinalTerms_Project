# Asset giao diện PCK

| Thư mục          | Nội dung                  |
| ---------------- | ------------------------- |
| `hero/`          | Ảnh banner Trang chủ      |
| `welcome/`       | Đồ họa màn hình chào mừng |
| `mascot/`        | Hình linh vật             |
| `branding/`      | Logo và nhận diện         |
| `illustrations/` | Hình minh họa dùng chung  |

Đặt một hoặc nhiều ảnh trong hero/. Hỗ trợ WebP, JPG, JPEG, PNG và AVIF. Trang chủ tự đọc các ảnh theo thứ tự tên tự nhiên (ví dụ hero1.png, hero2.png), chuyển mỗi 7 giây và lặp lại.

Ảnh ngang khoảng 1600 × 600 px là điểm bắt đầu phù hợp. Đặt chủ thể gần giữa hoặc hơi lệch phải vì phần chữ nằm bên trái trên máy tính và ảnh được cắt theo khung. Tải lại trang sau khi thêm hoặc đổi ảnh. Các thư mục còn lại đã sẵn sàng để lưu thiết kế.
